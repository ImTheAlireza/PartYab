# چایلد تم PartYab

پایه: **Hello Elementor** (والد) — همه استایل‌ها و قابلیت‌ها در همین چایلد تم است.

## نصب

1. قالب والد **Hello Elementor** را از پیشخوان نصب و فعال کن.
2. بسته را بساز: `bash tools/package-theme.sh` → خروجی `dist/part-yab.zip`
3. در وردپرس: **نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته** → ZIP را آپلود و فعال کن.

## ساختار

```
part-yab/
├── style.css            شناسنامه قالب (عمداً خالی)
├── functions.php        بوت‌استرپ + نسخه‌گذاری فایل‌ها
├── inc/
│   ├── setup.php        ویژگی‌ها، منوها، اندازه تصاویر، پاک‌سازی هد
│   ├── enqueue.php      بارگذاری دارایی‌ها + preload فونت + حذف فونت والد
│   ├── security.php     سخت‌سازی پایه (XML-RPC، REST کاربران، SVG، خطای ورود)
│   ├── woocommerce.php  ستون/تعداد حلقه، حالت خالی، تب‌های محصول
│   └── compat-ui.php    باکس خودروی من، بج سازگاری، فیلتر آرشیو
└── assets/
    ├── css/base.css     توکن‌ها، تایپوگرافی، اجزای مشترک، RTL، بریک‌پوینت
    ├── js/main.js       تعاملات پایه بدون jQuery
    ├── fonts/           وزیرمتن (متغیر + استاتیک) + لایسنس OFL
    └── img/             لوگوی **موقت** در سه نسخه
```

## قاعده‌های کدنویسی این تم

- هیچ فایل بالای ۳۰۰ خط نمی‌رود؛ هر قابلیت یک ماژول در `inc/`.
- هیچ رنگ/فاصله‌ای هاردکد نمی‌شود؛ همه از توکن‌های `:root` در `base.css`.
- هیچ `!important` در CSS.
- هر دارایی با `filemtime` نسخه می‌گیرد (بدون کش کهنه).
- جاوااسکریپت بدون jQuery و با `defer`.
- خصوصیات منطقی (`margin-inline`, `padding-inline`) جای چپ/راست.
