جدول سازگاری قطعه و خودرو برای ووکامرس؛ با کاتالوگ خودروهای ایرانی و وارداتی، پنج حالت سازگاری و فیلتر «فقط سازگار».

== Description ==

این افزونه برای فروشگاه‌های قطعات یدکی نوشته شده و روی ووکامرس سوار می‌شود:

* کاتالوگ خودرو در `data/vehicles.json` (۱۰ برند، ۳۳ مدل، سال و تیپ موتور) — قابل فیلتر با `partyab_vehicles_catalog`.
* جدول اختصاصی `{prefix}partyab_fitment` برای ردیف‌های سازگاری هر محصول (مدل، از سال، تا سال، وضعیت، شرط).
* متاباکس «سازگاری خودرو» روی محصول + ستون خلاصه در فهرست محصولات.
* پنج حالت: سازگار / سازگار با شرط / ناسازگار / ثبت‌نشده / عمومی (+ حالت «انتخاب خودرو» وقتی خودرویی انتخاب نشده).
* REST: `partyab/v1/vehicles`، `/search`، `/state`، `/vehicle`، `/coverage`.
* فیلتر «فقط سازگار» در آرشیو محصولات با `?compat=1`.
* ایمپورت/اکسپورت CSV در «ابزارها → سازگاری پارت‌یاب».
* نمونهٔ داده: `sample/products.csv` (برای ایمپورت ووکامرس) و `sample/fitment.csv` (برای ایمپورت همین افزونه).

== Installation ==

1. پوشهٔ افزونه را در `wp-content/plugins/` بگذارید و فعال کنید.
2. ووکامرس را فعال کنید (لازم است).
3. محصولات نمونه را از «محصولات → ایمپورت» با `sample/products.csv` وارد کنید.
4. سپس «ابزارها → سازگاری پارت‌یاب» و `sample/fitment.csv` را ایمپورت کنید.

== Frequently Asked Questions ==

= اگر برای محصولی ردیفی ثبت نشود چه می‌شود؟ =
وضعیت «ثبت‌شده نیست» (نامشخص، نه ناسازگار) نمایش داده می‌شود؛ این تفکیک عمدی است تا فروش از دست نرود و کاربر گمراه نشود.

= خودرو کجا ذخیره می‌شود؟ =
در کوکی `partyab_vehicle` (JSON امضاشده با اعتبارسنجی سمت سرور). انتخاب خودرو نیازی به حساب کاربری ندارد.
