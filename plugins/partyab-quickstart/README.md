# PartYab Quick Start — نصب یک‌کلیکی

یک دکمه، تمام نصب. مناسب محیط تست/لوکال و تحویل دمو.

## چه کاری می‌کند (۴ مرحله)

| مرحله | کار |
|---|---|
| ۱ · افزونه‌ها | نصب و فعال‌سازی ووکامرس، المنتور، المنتور پرو (از `vendor/` و اگر نبود از مخزن وردپرس) |
| ۲ · قالب | نصب Hello Elementor (والد) + چایلد تم پارتیاب و فعال‌سازی چایلد |
| ۳ · تنظیمات | پیوند یکتا، تهران، هفته از شنبه، تومان، کیلوگرم/سانتی‌متر، Container فعال، خاموش‌کردن رنگ/فونت پیش‌فرض المنتور، عرض ۱۲۴۰ |
| ۴ · محتوا | ۵ دسته محصول، **۶ محصول تست با عکس**، ۱۴ ردیف داده سازگاری، ۳ صفحه، منوی اصلی |

هر مرحله در یک درخواست تازه اجرا می‌شود (چون ووکامرس بعد از فعال‌سازی در همان درخواست کامل بالا نمی‌آید) و گزارش رنگی می‌دهد.
همه مراحل **تکرارپذیر** هستند: اجرای دوباره چیزی را خراب نمی‌کند.

## نصب

1. ZIP نصب‌کننده را از releases دانلود کن.
2. `افزونه‌ها ← افزودن ← بارگذاری` → آپلود → **فعال‌سازی**.
3. از منوی **«نصب سریع»** دکمه را بزن. صبر کن تا به صفحه گزارش برسد.

## خط فرمان (جایگزین)

```bash
wp partyab quickstart
```

## بسته‌های همراه

```
vendor/
├── part-yab.zip            چایلد تم
├── partyab-compat.zip      موتور سازگاری
├── compat-sample.csv       ۱۴ ردیف داده سازگاری
├── demo-images/            ۶ عکس محصول
├── Elementor.zip           (فقط در بسته full)
└── elementor-pro-*.zip     (فقط در بسته full)
```

اگر افزونه‌ای را خودت ZIP داری (مثلاً ووکامرس فارسی)، فایلش را با همان نام در `vendor/` بگذار — نصب‌کننده اول از آن استفاده می‌کند و بعد سراغ مخزن وردپرس می‌رود.

## چیزهایی که انجام نمی‌دهد

- لایسنس المنتور پرو را فعال نمی‌کند (کلید لایسنس دست خودت است).
- قالب‌های صفحه (Theme Builder) و دموها را نمی‌سازد — کار قطعه ۳ و ۷ است.
- درگاه پرداخت واقعی وصل نمی‌کند.

## تغییرات

### ۱٫۱٫۱
- **رفع باگ مرگبار:** دو تابع همنام `partyab_qs_page()` وجود داشت (سازنده صفحه + رندر پیشخوان) که باعث خطای
  `Cannot redeclare partyab_qs_page()` و شکست فعال‌سازی می‌شد. سازنده صفحه به `partyab_qs_create_page()` و رندر به
  `partyab_qs_render_page()` تغییر نام داد.
- محافظ کپی تکراری افزونه (جلوگیری از `redeclare` وقتی دو نسخه نصب شده باشد).
- بارگذاری ماژول‌ها داخل `try/catch` + نمایش خطا در پیشخوان به‌جای صفحه سفید.
- پنل «عیب‌یابی محیط» روی همان صفحه (PHP، حافظه، سقف آپلود، ZipArchive، دسترسی پوشه).
- آپلود بسته‌های جاافتاده (Elementor/Pro/WooCommerce/قالب) از خود صفحه نصب.
