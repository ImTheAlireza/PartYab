# بسته‌های آماده نصب

آخرین ساخت: نسخه **۲٫۵٫۱** قالب (رفع بارگذاری هیرو Mustang Shelby GT500 بدون دیکودر WASM، پوستر تا اولین فریم واقعی، دکمه‌های سبک B1+B4 و ثانویه B2، لودر L2، صدای قابل‌خاموش). نسخه نصب‌کننده **۱٫۴٫۰**.

| فایل | حجم | لینک دانلود مستقیم |
|---|---|---|
| **نصب‌کننده کامل** (Elementor + Pro داخلش) | ۳۰MB | [partyab-quickstart-full.zip](./partyab-quickstart-full.zip) |
| نصب‌کننده سبک (المنتور از مخزن وردپرس) | ۴٫۲MB | [partyab-quickstart.zip](./partyab-quickstart.zip) |
| چایلد تم پارتیاب | ۳٫۴MB | [part-yab.zip](./part-yab.zip) |
| افزونه سازگاری قطعه-خودرو | ۱۱KB | [partyab-compat.zip](./partyab-compat.zip) |

## تنظیم صدا

پس از نصب، از **نمایش ← حرکت و صدا** می‌توانید افکت صوتی ترنزیشن صفحه‌ها را روشن/خاموش کنید. کلید «صدا» در فوتر سایت هم برای بازدیدکننده وجود دارد. مرورگرها صدا را پس از نخستین کلیک/لمس کاربر پخش می‌کنند.

## نصب ۳ قدمی

1. وردپرس تازه (PHP 8.3).
2. `افزونه‌ها ← افزودن ← بارگذاری` → `partyab-quickstart-full.zip` → نصب → **فعال‌سازی**.
3. منوی **«نصب سریع»** → دکمه نارنجی → صبر تا پایان گزارش.

## چه چیزی نصب می‌شود

- افزونه‌ها: ووکامرس، المنتور، المنتور پرو، افزونه سازگاری
- قالب: Hello Elementor + چایلد تم پارتیاب (فونت وزیرمتن داخلش)
- تنظیمات: فارسی، تهران، هفته از شنبه، تومان، کیلوگرم/سانتی‌متر، Container فعال، عرض ۱۲۴۰
- محتوا: ۵ دسته، ۶ محصول با عکس، ۱۴ ردیف سازگاری، ۳ صفحه، منوی اصلی
