# PartYab — بازسازی کامل صفحات با طراحی نسخه ۲

تمام صفحات سایت **از نو** و بر اساس فایل مرجع [`styleguide.html`](styleguide.html)
ساخته شده‌اند: ۲۳ صفحه HTML مستقل، راست به چپ (RTL)، فارسی، بدون هیچ وابستگی خارجی
(نه CDN، نه فونت گوگل، نه کتابخانه JS). فقط HTML + CSS + JS خالص.

## اجرا

```bash
cd site
python3 build.py          # ساخت/بازسازی همهٔ *.html
python3 check.py          # اعتبارسنجی ۲۳ صفحه
python3 -m http.server 8080 --bind 0.0.0.0
# سپس http://localhost:8080/index.html
```

> **مهم:** `site/build.py` با `build.py` ریشهٔ مخزن فرق می‌کند. اسکریپت ریشه
> `index.html` و `CHECKLIST.md` چک‌لیست را میسازد و نباید برای این پوشه اجرا شود.
> صفحات `site/*.html` خروجی هستند؛ هر تغییر باید در `build.py` یا `assets/`
> انجام شود و دوباره ساخته شود.

## صفحات (۲۳)

| گروه | صفحات |
|---|---|
| اصلی و فروشگاه | `index` · `shop` · `product` · `search` · `brands` · `compare` |
| سبد و خرید | `cart` · `checkout` · `thankyou` · `track` |
| حساب کاربری | `account` · `orders` · `wishlist` · `garage` |
| محتوا | `blog` · `article` · `about` · `contact` · `faq` · `warranty` · `guide` |
| سیستم | `404` · `sitemap` |

همهٔ صفحات هدر سه لایه، ناوبری، breadcrumb، کشوی موبایل، فوتر، اسپرایت آیکون،
و `H1` یگانه دارند. لینک‌های داخلی همگی به یکی از همین ۲۳ صفحه ختم می‌شوند.

## معماری

| فایل | نقش |
|---|---|
| `styleguide.html` | کپی دقیق فایل مرجع پیوست‌شده (منبع طراحی) |
| `build.py` | تولیدکنندهٔ ۲۳ صفحه؛ ۱۲ محصول، ۱۲ تصویر SVG برداری، ناوبری و توابع مشترک |
| `check.py` | بررسی ساختار، یک H1، لینک‌ها/دارایی‌های محلی، شناسه‌های آیکون و نشت تمپلیت |
| `assets/css/partyab.css` | سیستم طراحی استخراج‌شده از styleguide (توکن‌ها، هدر، هیرو، کارت محصول، فوتر، انیمیشن‌ها) + `@font-face` محلی |
| `assets/css/pages.css` | لایهٔ صفحات: هیرو داخلی، فیلتر‌ها، PDP، سبد، چکاوت، حساب، مقایسه، مقاله، FAQ، واکنش‌گرایی |
| `assets/js/partyab.js` | بستهٔ حرکتی styleguide: tilt، شمارنده، reveal، علاقه‌مندی، فلش‌سل/شمارش معکوس، ریل، پرواز به سبد، دکمهٔ بازگشت |
| `assets/js/pages.js` | تعاملات صفحات: تب‌ها، گالری، استپر، حذف/کوپن سبد، روش پرداخت، فیلتر‌ها، FAQ، فرم‌ها، جستجو |
| `assets/partials/sprite.html` | ۴۳ `<symbol>` SVG که به صورت inline در هر صفحه تزریق می‌شود |
| `assets/fonts/Vazirmatn-Variable.woff2` | فونت متغیر selfhosted |

هویت بصری: `navy #0E2340` + `orange #FF6A00`، زمینهٔ روشن `#F5F7FB`،
فونت وزیرمتن ۱۰۰–۹۰۰، شعاع‌های ۸/۱۰/۱۴/۲۰/۲۸، کانتینر ۱۲۸۰px، RTL کامل،
و پشتیبانی از `prefers-reduced-motion`.

## اتصال به وردپرس / ووکامرس

صفحات `site/` یک پیاده‌سازی مستقل و کامل‌اند (دمو/مرجع نهایی طراحی).
برای اینکه **سایت وردپرسی موجود** هم همان زبان بصری را بگیرد، فایل
`theme/part-yab/assets/css/design-v2.css` اضافه شد:

- توکن‌های قدیمی `--pb-*` را به پالت و شعاع‌های نسخه ۲ نگاشت می‌کند؛
- هدر، هیرو، دکمه‌ها، دسته‌ها، بنرها، کارت محصول ووکامرس، فرم‌ها، جدول‌ها و فوتر را بازنویسی می‌کند؛
- در `inc/enqueue.php` با اولویت ۴۰ و به عنوان آخرین استایل صف‌بندی می‌شود
  (وابستگی به `partyab-woo` فقط وقتی ثبت شده باشد اضافه می‌شود)؛
- نشانه‌گذاری PHP، افزونه‌ها و المنتور دست‌نخورده می‌مانند تا چیزی نشکند.

نسخهٔ قالب به `2.0.0` ارتقا یافت. بسته‌های `releases/*.zip` عمداً بازسازی نشدند؛
در صورت نیاز: `bash tools/build-release.sh --full`.

## تست‌های انجام‌شده

```bash
cd site && python3 build.py && python3 check.py     # ۲۳/۲۳ ✓
node --check assets/js/partyab.js
node --check assets/js/pages.js
node ../tools/php-run.mjs ../tools/php-lint.php ../theme/part-yab   # ۲۵ فایل، ۰ خطا
node ../tools/php-run.mjs ../tools/php-test.php                     # همه تست‌ها سبز
```

همچنین با مرورگر headless در عرض‌های ۱۴۴۰/۷۶۸/۳۹۰ پیکسل روی هر ۲۳ صفحه بررسی شد:
بدون سرریز افقی، بدون خطای JS/کنسول، فونت وزیرمتن، ۴۳ آیکون، `H1` یگانه،
و تعاملات (کشوی موبایل، تب‌ها، گالری، استپر، حذف سبد، کوپن، نمای لیست، افزودن به سبد) همگی سبز.
