# PartYab — چک‌لیست ساخت قالب وردپرس فروشگاه لوازم یدکی

قالب فروشگاهی لوازم یدکی با **المنتور**، شامل ۵ دموی صفحه اصلی و صفحات فروشگاهی کامل.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.html` | چک‌لیست تعاملی — تک‌فایل، بدون نیاز به اینترنت. تیک‌ها در مرورگر ذخیره می‌شوند. |
| `CHECKLIST.md` | نسخه مارک‌داون برای چاپ / Notion / گیت‌هاب |
| `PLAN.md` | **پلن اجرایی**: ۶ اسپرینت، دروازه‌های کیفیت، ریسک‌ها، تصمیم‌های باز |
| `plan/roadmap.svg` | نقشه راه تصویری (گاه‌نگار ۸ هفته‌ای + دروازه‌ها) |
| `docs/` | خروجی قطعه ۰: بریف، تصمیم‌نامه، پرسونا، سبد افزونه، ساختار URL |
| `content/*.json` | منبع محتوا (۱۶ قطعه) |
| `app/template.html` | قالب HTML/CSS/JS |
| `build.py` | ساخت `index.html` و `CHECKLIST.md` از محتوا |

## پلن پروژه

- **پروژه نوشن:** صفحه «PartYab — قالب فروشگاه لوازم یدکی (المنتور)» — شامل نقشه راه، گانت، پلن ۶ اسپرینتی، ۱۶ زیرصفحه چک‌لیست، ریسک‌ها و تصمیم‌های باز.
- **خلاصه:** ۳۵۴ کار · ۱۵۵ بحرانی · ۲۱۶ ساعت · ۸ هفته · مسیر بحرانی ۰ ← ۱ ← ۲ ← ۵ ← ۶ ← ۹ ← ۱۵.

```bash
python3 build.py     # بازسازی خروجی‌ها بعد از ویرایش content/*.json
python3 -m http.server 8080
```
