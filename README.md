# PartYab — چک‌لیست ساخت قالب وردپرس فروشگاه لوازم یدکی

قالب فروشگاهی لوازم یدکی با **المنتور**، شامل ۵ دموی صفحه اصلی و صفحات فروشگاهی کامل.

> **بازسازی نسخه ۲ (طراحی جدید):** تمام صفحات بر اساس `styleguide.html` از نو ساخته شده‌اند.
> خروجی کامل و قابل اجرا در [`site/`](site/README.md) است (۲۳ صفحه HTML مستقل، RTL، بدون وابستگی خارجی).
> چایلد تم وردپرس نیز از طریق `theme/part-yab/assets/css/design-v2.css` همان پالت و توکن‌ها را دریافت می‌کند.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.html` | چک‌لیست تعاملی — تک‌فایل، بدون نیاز به اینترنت. تیک‌ها در مرورگر ذخیره می‌شوند. |
| `CHECKLIST.md` | نسخه مارک‌داون برای چاپ / Notion / گیت‌هاب |
| `PLAN.md` | **پلن اجرایی**: ۶ اسپرینت، دروازه‌های کیفیت، ریسک‌ها، تصمیم‌های باز |
| `plan/roadmap.svg` | نقشه راه تصویری (گاه‌نگار ۸ هفته‌ای + دروازه‌ها) |
| `docs/` | خروجی قطعه ۰: بریف، تصمیم‌نامه، پرسونا، سبد افزونه، ساختار URL |
| `content/*.json` | منبع محتوا (۱۶ قطعه) |
| `app/template.html` | قالب HTML/CSS/JS |
| `build.py` | ساخت `index.html` و `CHECKLIST.md` از محتوا |
| `site/` | **بازسازی کامل ۲۳ صفحه** با طراحی جدید — [راهنما](site/README.md) |
| `theme/part-yab/assets/css/design-v2.css` | پل طراحی نسخه ۲ برای چایلد تم وردپرس/ووکامرس |

## پلن پروژه

- **پروژه نوشن:** صفحه «PartYab — قالب فروشگاه لوازم یدکی (المنتور)» — شامل نقشه راه، گانت، پلن ۶ اسپرینتی، ۱۶ زیرصفحه چک‌لیست، ریسک‌ها و تصمیم‌های باز.
- **خلاصه:** ۳۵۴ کار · ۱۵۵ بحرانی · ۲۱۶ ساعت · ۸ هفته · مسیر بحرانی ۰ ← ۱ ← ۲ ← ۵ ← ۶ ← ۹ ← ۱۵.

```bash
python3 build.py     # بازسازی خروجی‌ها بعد از ویرایش content/*.json
python3 -m http.server 8080
```

## بازسازی نسخه ۲ (طراحی جدید)

`site/` یک پیاده‌سازی مستقل و کامل از تمام صفحات با زبان بصری `styleguide.html` است؛
این پوشه جدا از چک‌لیست تک‌فایل `index.html` و جدا از `build.py` ریشه است.

```bash
cd site
python3 build.py                 # ساخت ۲۳ صفحه HTML
python3 check.py                 # اعتبارسنجی ساختار، لینک‌ها و آیکون‌ها
python3 -m http.server 8080      # پیشنمایش روی http://localhost:8080
```

چایلد تم `theme/part-yab/` همان توکن‌ها را از `assets/css/design-v2.css` میگیرد که
آخرین استایل صف‌بندی‌شده است (حتی بعد از `woo.css`)؛ بنابراین هدر، هیرو، دکمه‌ها،
کارت محصول، ووکامرس و فوتر در سایت وردپرسی هم با پالت نسخه ۲ دیده می‌شوند.
توضیح کامل: [site/README.md](site/README.md).

## نصب سریع (یک کلیک)

بسته `partyab-quickstart` را آپلود و فعال کن، بعد از منوی **«نصب سریع»** دکمه را بزن.
نصب ووکامرس و المنتور و پرو، قالب، تنظیمات فارسی/تومان، ۶ محصول با عکس، صفحات، منو و داده سازگاری — همه با هم.
ساخت بسته: `bash tools/build-release.sh --full` → خروجی در `releases/`.
