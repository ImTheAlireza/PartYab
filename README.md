# PartYab — پارت‌یاب

نمونهٔ قابل‌کلیک (High-fidelity UI prototype) برای فروشگاه قطعات خودرو **پارت‌یاب**؛
قالب راست‌چین ووکامرس + افزونهٔ سازگاری قطعه و خودرو.

> این پروژه در این مرحله فقط **طراحی رابط کاربری** است: HTML/CSS/JS ساده و بدون بیلد،
> با داده‌های نمایشی. هیچ داده یا قیمتی برای خرید واقعی قابل اتکا نیست.

## اجرا

```bash
python3 -m http.server 3000 --bind 0.0.0.0
# سپس: http://localhost:3000
```

## صفحات

| فایل | توضیح |
|---|---|
| `index.html` | صفحهٔ اصلی: هدر، انتخاب‌گر خودرو، دسته‌ها، پرفروش‌ها، برندها، سه حالت سازگاری، راهنما، خبرنامه، فوتر |
| `shop.html` | فهرست محصولات: نوار خودرو، فیلترهای کنار صفحه/کشویی، مرتب‌سازی، چیپ فیلترها، حالت بی‌نتیجه، صفحه‌بندی |
| `product.html?id=p1` | صفحهٔ محصول: گالری، کد OEM/SKU، پنل سازگاری، خرید، تب‌ها، جدول خودروهای سازگار، محصولات مرتبط، نوار خرید موبایل |

## ساختار

```
assets/
  css/style.css        سیستم طراحی (توکن‌ها، کامپوننت‌ها، ریسپانسیو)
  js/data.js           دادهٔ نمایشی: خودروها، دسته‌ها، ۱۲ محصول، برندها
  js/app.js            آیکون‌ها، کامپوننت هدر/فوتر، انتخاب‌گر خودرو، فیلترها، سبد نمونه
  fonts/               Vazirmatn (self-hosted, woff2)
  img/                 تصاویر تولیدشده برای دمو
```

## نکات طراحی

- **رنگ‌ها:** سرمه‌ای `#132238`، کهربایی `#F59E0B`، پس‌زمینه `#F7F9FC`
- **فونت:** Vazirmatn، خودمیزبان (بدون وابستگی به CDN)
- **RTL کامل** و استفاده از ویژگی‌های منطقی CSS (`inset-inline`, `margin-inline`)
- **سه حالت سازگاری** روی کارت و صفحهٔ محصول: سازگار / ناسازگار / سازگاری ثبت نشده
- انتخاب خودرو در `localStorage` ذخیره می‌شود و بین صفحات باقی می‌ماند
- بریک‌پوینت‌ها: ۱۱۸۰ / ۱۰۲۴ / ۸۶۰ / ۶۴۰ / ۳۸۰ پیکسل
- همهٔ وضعیت‌ها با **متن + آیکون** مشخص می‌شوند، نه فقط رنگ

## قدم بعدی پیشنهادی

1. تبدیل همین UI به قالب وردپرس (header.php / footer.php / archive-product.php / single-product.php)
2. ساخت افزونهٔ `PartYab Fitment`: جدول `partyab_fitment` + متاباکس تب سازگاری + ایمپورت CSV
3. پیاده‌سازی انتخاب‌گر خودرو با REST API ووکامرس و کش نتایج
