# ممیزی جداگانهٔ انیمیشن‌ها (نسخه ۲٫۶٫۱)

ابزار: `node tools/animation-audit.mjs`  
خروجی ماشین‌خوان: `preview/animation-audit.json`

هر بررسی روی یک کامپوننت جدا اجرا می‌شود؛ نتیجهٔ نهایی: **۵۲/۵۲ سبز**.

| بخش | بررسی‌ها |
|---|---|
| هدر | خط زیرین منو، خط زیرین اکشن‌ها |
| دکمه‌ها | بالاآمدن نرم B1، نبود لایهٔ ریپل شلوغ، سرخوردن آیکن B4، حاشیهٔ نارنجی B2، ثابت‌ماندن دکمهٔ ثانویه |
| دسته‌بندی | آیکن بدون keyframe پرشی، ناحیهٔ هاور ثابت، بازخورد هاور |
| محصول | بالاآمدن لایهٔ داخلی، ثابت‌ماندن ناحیهٔ هاور بیرونی، پایداری لبه بدون لرزش، نمای سریع |
| برند | لوگوهای مهارشده، توقف marquee با هاور |
| لودر | ورود اسلایدی، نبود پروگرس‌بار، انیمیشن لوگو، خروج اسلایدی، پنهان‌شدن، پوشش کامل پیش از ناوبری، مخفی‌شدن پس از ورود |
| صدا | نمایش کلید، بی‌صدا/باصدا شدن، پخش پس از ژست کاربر |
| فرم | فوکوس بدون هالهٔ اضافه، سلکت بدون هاله، دراپ‌داون متحرک، چک‌باکس pop-in |
| بازخورد | دیالوگ، توست، FAQ |
| اسکرول | نوار پیشرفت، دکمهٔ بالا، reveal همهٔ المان‌ها |
| هیرو سه‌بعدی | آماده‌شدن مدل، مخفی‌شدن fallback، چرخش آرام پیوسته، پاسخ به اسکرول |
| موبایل/دسترس‌پذیری | منوی موبایل، کاهش حرکت، توقف انیمیشن‌ها، نبود خطای صفحه |

اصلاحات کلیدی این دور:
- کارت محصول: ناحیهٔ تشخیص هاور (کارت بیرونی) ثابت است و فقط `.pb-product-card__surface` بالا می‌آید؛ بنابراین لبهٔ کارت زیر نشانگر نمی‌لرزد.
- لودر: فقط لوگوی پارتیاب با انیمیشن نرم؛ پروگرس‌بار و حلقهٔ اضافه حذف شد. پردهٔ تمام‌صفحه پیش از ناوبری کاملاً صفحه را می‌پوشاند و صفحهٔ مقصد پیش از اولین paint پوشیده است.
- صدا: افکت کوتاه WebAudio بدون فایل صوتی؛ از «نمایش ← حرکت و صدا» در وردپرس قابل خاموش شدن است و کلید فوتر هم دارد.
- هیرو: چرخش آرام پیوسته (turntable) + افست اسکرول/نشانگر، نورپردازی متعادل‌تر و سایهٔ ثابت روی زمین.
