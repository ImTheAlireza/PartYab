**قفل‌شده:** ۱۸ کار از ۲۱ — پایه، نسخه‌ها، افزونه‌ها، تحویل دمو، پرسونا، مدل فروش، سیاست‌ها، برند، فونت، سازگاری، مقایسه، زبان، URL، بریک‌پوینت، بودجه عملکرد، KPI.

**باقی‌مانده (وابسته به تو):**

| کار | چه چیزی لازم است |
|---|---|
| ۰-۰۲ | خرید و فعال‌سازی لایسنس Elementor Pro |
| ۰-۰۴ | دسترسی هاست/دامنه برای ساخت سه محیط |
| ۰-۱۳ | تأیید نام برند و طراحی لوگو در سه نسخه |

> بعد از رفع این سه مورد، دروازه کیفیت قطعه ۰ رد می‌شود و قطعه ۱ (زیرساخت فنی) شروع می‌شود.
