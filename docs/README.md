## وضعیت قطعه ۰

**قفل‌شده:** ۲۰ کار از ۲۱ — پایه، نسخه‌ها، افزونه‌ها، تحویل دمو، پرسونا، مدل فروش، سیاست‌ها، برند، فونت، سازگاری، مقایسه، زبان، URL، بریک‌پوینت، بودجه عملکرد، KPI.

**باقی‌مانده (وابسته به تو):**

| کار | چه چیزی لازم است |
|---|---|
| ۰-۰۴ | اجرای واقعی ساخت سه محیط — منتظر ۴ جواب فنی (روش در `DEPLOY.md` نوشته شد) |
| ۰-۱۳ | نام برند و لوگوی نهایی — **معلق به تصمیم تو**؛ فعلاً placeholder در `theme/part-yab/assets/img/` |

**بسته‌شده:** ۰-۰۲ (Elementor Pro موجود است).

> بعد از رفع این سه مورد، دروازه کیفیت قطعه ۰ رد می‌شود و قطعه ۱ (زیرساخت فنی) شروع می‌شود.
