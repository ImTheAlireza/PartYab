# راه‌اندازی لوکال (قدم‌به‌قدم)

هدف: یک سایت تست تمیز روی Local با PHP 8.3 که دقیقاً همان چیزی باشد که بعداً به هاست می‌رود.
زمان تقریبی: ۲۵ دقیقه.

---

## قدم ۰ — این جلسه

| مورد | مقدار |
|---|---|
| PHP | **۸٫۳** (تنظیم شد) |
| وردپرس | آخرین نسخه پایدار، زبان **فارسی** |
| قالب والد | Hello Elementor |
| قالب فعال | PartYab (چایلد) |
| هاست | ندارد — فعلاً لازم نیست |
| Staging | ندارد — وقتی هاست گرفتی، «ساخت staging یک‌کلیکی» می‌شود معیار انتخاب هاست |

## قدم ۱ — تنظیمات اولیه وردپرس

1. `تنظیمات ← همگانی`: عنوان سایت، زبان **فارسی**، منطقه زمانی **تهران**، تاریخ شمسی اگر افزونه دارد.
2. `تنظیمات ← پیوندهای یکتا`: **نام نوشته** (نه ساده). بعد از تغییر، یک‌بار Save.
3. `تنظیمات ← خواندن`: نمایش ۱۲ نوشته؛ `noindex` **تیک نخورده** (لوکال هستیم ولی برای تست سئو لازم است).
4. `تنظیمات ← بحث`: غیرفعال کردن کامل کامنت‌ها (فروشگاه کامنت نمی‌خواهد).
5. `کاربران`: یک کاربر مدیر با نام واقعی؛ کاربر `admin` را حذف یا تغییر نام بده.

## قدم ۲ — افزونه‌های پایه (به همان ترتیب)

| # | افزونه | نکته |
|---|---|---|
| ۱ | Elementor | نسخه رایگان |
| ۲ | Elementor Pro | لایسنس خودت را فعال کن |
| ۳ | WooCommerce | ویزارد را **کامل** رد کن |
| ۴ | Hello Elementor | فقط نصب و فعال — فعال‌سازی نهایی با چایلد است |

## قدم ۳ — ووکامرس

1. ویزارد: کشور **ایران**، واحد پول **IRR** (نمایش تومان در قطعه ۵ با اسنیپت انجام می‌شود)، وزن **کیلوگرم**، ابعاد **سانتی‌متر**.
2. `ووکامرس ← تنظیمات ← حساب‌ها`: اجازه ثبت‌نام در چک‌اوت **فعال** (خرید مهمان هم فعال).
3. `ووکامرس ← تنظیمات ← محصولات`: وزن/ابعاد فعال، مدیریت موجودی فعال، آستانه کم‌موجودی ۲.
4. `ووکامرس ← تنظیمات ← پیشرفته`: صفحه سبد، چک‌اوت، حساب — همه ساخته شوند.
5. پرداخت: فعلاً **پرداخت در محل** برای تست؛ درگاه واقعی در قطعه ۱۲.

## قدم ۴ — نصب چایلد تم

```bash
bash tools/package-theme.sh          # می‌سازد: dist/part-yab.zip
```

در وردپرس: `نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته` → ZIP → **فعال‌سازی**.

بعد از فعال‌سازی، سه چیز را چک کن:
- فونت فارسی وزیرمتن روی سایت اعمال شده (متن فارسی نباید Tahoma باشد).
- در کنسول مرورگر خطای ۴۰۴ برای `base.css` یا فونت نباشد.
- `نمایش ← منوها`: سه منو ساخته شده باشد (اصلی، نواری بالا، فوتر).

## قدم ۵ — تنظیمات المنتور

1. `المنتور ← تنظیمات ← ویژگی‌ها`: **Flexbox Container** فعال (از روز اول با Container بساز).
2. `المنتور ← تنظیمات ← سبک`: **غیرفعال** کردن رنگ‌ها و فونت‌های پیش‌فرض (تا فقط توکن‌های ما اثر کنند).
3. `المنتور ← تنظیمات ← پیشرفته`: حالت ویرایش `Safe Mode` را بعد از پایداری خاموش کن.
4. در Elementor Pro: `Site Settings` را باز کن و منتظر قطعه ۳ باش — Global Colors/Fonts آنجا تعریف می‌شود.

## قدم ۶ — نصب افزونه سازگاری (قطعه ۲)

```bash
bash tools/package-plugin.sh partyab-compat   # می‌سازد: dist/partyab-compat.zip
```

1. `افزونه‌ها ← افزودن ← بارگذاری` → ZIP → **فعال‌سازی**.
2. منوی **سازگاری** در پیشخوان ظاهر می‌شود؛ جدول باید `۰ ردیف` نشان دهد.
3. چهار محصول تست با این SKU بساز (نام و SKU مهم است):

| SKU | محصول |
|---|---|
| PB-BRK-001 | لنت ترمز جلو پراید |
| PB-FLT-002 | فیلتر روغن پژو |
| PB-SPK-003 | شمع سمند |
| PB-BAT-004 | باتری ۵۵ آمپر |

4. منوی **سازگاری** → آپلود `data/compat-sample.csv` → حالت **جایگزینی کامل** → ایمپورت.
5. انتظار: **۹ ردیف درج، ۰ رد** و در جدول «برندهای ثبت‌شده» چهار برند دیده شود.

> اگر ردیفی رد شد، گزارش می‌گوید کدام SKU پیدا نشد — یعنی محصولش ساخته نشده.

## قدم ۷ — تست دود (Smoke Test)

| # | تست | انتظار |
|---|---|---|
| ۱ | باز کردن خانه | بدون خطای PHP، فونت درست |
| ۲ | یک محصول | قیمت با رقم لاتین، دکمه افزودن به سبد کار کند |
| ۳ | افزودن به سبد و رفتن به چک‌اوت | بدون خطا، جمع درست |
| ۴ | موبایل واقعی | بدون اسکرول افقی |
| ۵ | منوی سازگاری | آمار جدول درست |
| ۶ | کنسول مرورگر | هیچ خطای JS |

اگر همه سبز بود، پیام بده: می‌رویم قطعه ۳ (Theme Builder و Global Colors).

## خطاهای رایج

| نشانه | علت | راه‌حل |
|---|---|---|
| صفحه سفید بعد از فعال‌سازی چایلد | Hello Elementor نصب نیست | والد را نصب و فعال کن، بعد چایلد |
| فونت اعمال نمی‌شود | مسیر `assets/fonts` پیدا نشد | ZIP را دوباره از `tools/package-theme.sh` بساز |
| خطای ۴۰۴ بعد از تغییر پیوندها | بازنویسی .htaccess | `تنظیمات ← پیوندهای یکتا` را یک‌بار Save کن |
| منوی «سازگاری» نیست | WooCommerce فعال نیست | افزونه سازگاری برای دسترسی به `manage_woocommerce` نیاز دارد |
| ایمپورت همه را رد می‌کند | SKUها با CSV نمی‌خوانند | SKU را دقیقاً `PB-BRK-001` بگذار |
