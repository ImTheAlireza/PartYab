> خروجی قطعه ۰ (تصمیم‌های بنیادی). هر تصمیم اینجا **قفل** است؛ تغییر بعدی یعنی بازبینی همه قطعه‌های بعدی.

## ۱. محصول

قالب فروشگاهی وردپرس برای فروش **لوازم یدکی خودرو** با المنتور پرو، شامل ۵ دموی صفحه اصلی و مسیر خرید کامل.
تفاوت اصلی با یک فروشگاه معمولی: کاربر با **«خودروی من»** و **«شماره فنی»** می‌رسد، نه با دسته‌بندی.

- نام: **PartYab / پارتیاب**
- تگ‌لاین: **«قطعه درست، همان بار اول»**
- لحن: فنی، مطمئن، کوتاه. بدون شوخی و بدون صفت‌های تبلیغاتی توخالی.

## ۳. استک قفل‌شده

| لایه | انتخاب |
|---|---|
| قالب پایه | Hello Elementor + چایلد تم اختصاصی |
| صفحه‌ساز | Elementor Pro (Theme Builder + WooCommerce Builder + Loop Grid) |
| فروشگاه | WooCommerce (تومان، کیلوگرم، سانتی‌متر) |
| PHP / DB | PHP 8.3 · MySQL 8 · `memory_limit` ۲۵۶M |
| وردپرس | آخرین نسخه پایدار (فعلاً شاخه ۶.x) |
| زبان | فارسی، تک‌زبانه، `rtl` |
| سازگاری خودرو | **جدول اختصاصی** در دیتابیس |
| تحویل دموها | **Template Kit** (هر دمو یک پکیج مستقل) |

> **چرا جدول اختصاصی:** با چند هزار محصول و فیلتر «سازگار با خودروی من»، متای محصول به کوئری‌های سنگین می‌رسد. جدول اختصاصی ایندکس‌پذیر است و جستجو در آن زیر ۵۰ms می‌ماند.

## ۴. محیط‌ها

| محیط | کاربرد | قواعد |
|---|---|---|
| Local | توسعه روزانه | `WP_DEBUG` روشن، داده نمونه |
| Staging | بازبینی و تست | نسخه‌ای از Production، `noindex` |
| Production | سایت نهایی | `WP_DEBUG` خاموش، کش و بک‌آپ فعال |

انتشار **یک‌طرفه** است: Local → Staging → Production. هرگز مستقیم روی Production طراحی نمی‌شود.

## ۵. سبد افزونه (حداکثر ۱۲ — لیست کامل در `PLUGIN-STACK.md`)

Elementor Pro · WooCommerce · افزونه سئو (Rank Math) · کش (LiteSpeed Cache) · بک‌آپ (UpdraftPlus) · SMTP (FluentSMTP) · فیلتر محصول (FacetWP یا مشابه) · CPT UI · افزونه تاریخ شمسی · OTP پیامکی · افزونه گزارش جستجو · افزونه فاکتور PDF

هر افزونه جدید فقط با **تست سرعت + تست تداخل RTL** اضافه می‌شود.

## ۶. مدل فروش و سیاست‌ها

- مدل: **خرده‌فروشی** در نسخه ۱؛ مدل داده از روز اول برای **عمده** آماده می‌شود (نقش کاربری «عمده‌فروش» + فیلد قیمت پله‌ای، بدون فعال‌سازی UI).
- ارسال: پیک تهران (همان‌روز) · پست پیشتاز (۲ روز) · تیپاکس · باربری برای اقلام سنگین.
- مرجوعی: ۷ روز، به شرط باز نشدن بسته‌بندی؛ قطعات برقی و نصب‌شده مستثنی.
- گارانتی: اصالت کالا + گارانتی شرکتی بر اساس برند.
- حداقل سفارش: ندارد.
- پرداخت: درگاه بانکی (زرین‌پال در نسخه ۱) + پرداخت در محل فقط برای تهران (اختیاری).
