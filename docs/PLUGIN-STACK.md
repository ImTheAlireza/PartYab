## افزونه‌های عمداً **نصب نمی‌شوند**

| افزونه | جایگزین ما |
|---|---|
| افزونه مقایسه محصول | کد سفارشی سبک، چون باید سازگاری خودرو را هم نشان دهد (D9) |
| افزونه علاقه‌مندی | کد سفارشی روی `user_meta` + کوکی مهمان |
| افزونه مگامنو | Elementor Pro (Mega Menu ویجت Nav) |
| افزونه جستجوی AJAX | کد سفارشی در چایلد + FacetWP برای آرشیو |
| افزونه چندزبانه | خارج از دامنه نسخه ۱ (D6) |
| افزونه بک‌آپ اضافه / بهینه‌سازی تصویر جدا | UpdraftPlus + تبدیل WebP در آپلود |

## معیار رد کردن افزونه

اگر هر یک از این‌ها را دیدی، حذفش کن:
- بیشتر از ۱۵۰KB JS اضافه می‌کند
- CSS آن با `!important` روی استایل ما اثر می‌گذارد
- در RTL جابه‌جا می‌شود یا اسکرول افقی می‌سازد
- صفحات سبد/چک‌اوت را کش می‌کند
- برای کاری نصب شده که یک اسنیپت ۲۰ خطی انجامش می‌دهد
