# ساختار دسته، برند و خودرو (قطعه ۶)

سه لایه‌ی مستقل روی محصول، تا هر کدام کار خودش را بکند:

| لایه | نوع | نمونه | مسیر | کاربرد |
|---|---|---|---|---|
| دسته قطعه | `product_cat` (ووکامرس) | سیستم ترمز، فیلترها، برق و باتری | `/product-category/brake-system/` | مرور فروشگاه، منو، نقشه سایت |
| برند قطعه | `pb_brand` (تخت) | ایساکو، بوش، کروز | `/brand/isaco/` | فیلتر برند، صفحه برند |
| خودرو | `pb_car` (سلسله‌مراتبی) | پراید → ۱۳۱ / ۱۱۱ / ۱۴۱ | `/car/pride/` | انتخاب خودرو، فیلتر سازگاری، بج سبز |

## چرا خودرو سلسله‌مراتبی است؟

برند خودرو سطح اول است و مدل فرزند آن. کوئری روی «پراید» با
`include_children` خودکار همه مدل‌ها را می‌آورد؛ محصول هم به برند و هم به مدل
وصل می‌شود تا شمارش ترم برند صفر نماند.

## API قالب

```php
partyab_find_car_term( 'پراید', '131' );   // WP_Term|null
partyab_car_tree();                         // [ [term, models[]], … ]
partyab_brand_terms();                      // WP_Term[] با count>0
partyab_product_terms_pills();              // چیپ برند و «سازگار با» در صفحه محصول
```

## فیلتر آرشیو

`partyab_filter_shop_by_car()` در `inc/compat-ui.php` اول ترم `pb_car` را با
کوکی خودرو تطبیق می‌دهد (tax_query). اگر ترم نبود، به جدول سازگاری CSV
برمی‌گردد. یعنی هم مسیر تاکسونومی و هم داده قدیمی کار می‌کند.

سایدبار (`inc/woocommerce.php`) چهار کارت دارد: خودروی من، دسته‌بندی، برند قطعه،
خودرو (برند + مدل‌های همان برند)، محدوده قیمت، فقط موجود.

## ساخت اولیه (نصب‌کننده ۱٫۳٫۰)

`partyab_qs_seed_taxonomies()` در مرحله «محتوا»:

1. ۱۰ برند خودرو رایج ایرانی و ۲۳ مدل می‌سازد (پراید، پژو، سمند، دنا، تیبا، ساینا، کوییک، شاهین، رانا، آریسان).
2. ۷ برند قطعه می‌سازد.
3. هر ۱۴ ردیف `compat-sample.csv` را به محصول و ترم خودرو وصل می‌کند.
4. محصولات دمو را به برند قطعه وصل می‌کند.

تکرارپذیر است: اگر ترم باشد دوباره ساخته نمی‌شود (`term_exists` با parent).

## افزودن خودرو یا برند جدید

پیشخوان ← محصولات ← «خودروها» یا «برند قطعه» ← افزودن.
برای مدل جدید، اول برند را انتخاب کنید و در فیلد «برند خودرو» (Parent) همان
برند را بگذارید.
