# بازطراحی پارتیاب — نسخه ۲

این نسخه تمام صفحه‌های چایلد تم را بر اساس `styleguide.html` بازطراحی می‌کند: سرمه‌ای تیره، نارنجی برند، وزیرمتن، کارت‌های گرد، هدر شیشه‌ای و حرکت‌های نرم.

## چه چیزی عوض شد

- **سیستم طراحی:** `assets/css/base.css` توکن‌ها، دکمه‌ها، فرم‌ها، بج‌ها، دیالوگ، توست و حالت‌های خالی را یکدست می‌کند. متغیرهای قدیمی `--pb-*` حفظ شده‌اند.
- **چیدمان:** `layout.css` هدر چسبان، جستجو، ناوبری، هیرو خودرو، انتخابگر خودرو و فوتر غنی را پیاده می‌کند.
- **فروشگاه:** `woo.css` و `redesign.css` کارت محصول، آرشیو، تک‌محصول، سبد، تسویه، حساب کاربری و رسید سفارش را پوشش می‌دهند.
- **محتوا:** `content.css` صفحه‌های درباره، تماس، FAQ، راهنما، مقاله و سیاست‌ها را یکدست می‌کند.
- **جستجو و سازگاری:** `search.css` و `compat-ui.css` پیشنهاد زنده، نتایج جستجو، بج سازگاری و جدول خودرو را با همان زبان بصری نشان می‌دهند.
- **حرکت:** `motion.css` و `assets/js/motion.js` اسکرول‌ریویل، تیلت سه‌بعدی هیرو، گلو/شاین کارت، مارکی برند، شمارش معکوس، پرواز به سبد، نوار پیشرفت اسکرول و دکمه توقف انیمیشن را اضافه می‌کنند. همه حرکت‌ها با `prefers-reduced-motion` و دکمه «توقف انیمیشن‌ها» غیرفعال می‌شوند.
- **تعامل:** `assets/js/ui.js` توست، دیالوگ، تب‌های دسترس‌پذیر، فیلتر موبایل، جستجوی FAQ و کمک‌های رابط را بدون jQuery انجام می‌دهد.

## لایه تعامل و لودر (نسخه ۲٫۱)

- `assets/css/interaction.css` و `assets/js/interaction.js`: ریپل و درخشش عبوری دکمه‌ها، هالهٔ همراه نشانگر روی کارت‌ها، انیمیشن آیکن‌ها، فوکوس نرم فرم‌ها، چک‌باکس/رادیوی سفارشی، دراپ‌داون سفارشی با کیبورد/ARIA، و رفع سرریز موبایل حساب.
- `assets/js/page-transition.js`: لودر رفت‌وبرگشت بین صفحه‌ها با لوگو، جاده و خودروی متحرک؛ روی لینک‌های داخلی و فرم‌های جستجو/خودرو فعال می‌شود و در `prefers-reduced-motion` حالت ساده می‌گیرد.
- هیرو: تصویر خودرو با آلفای پرمانند ادغام می‌شود، پارالاکس نشانگر، نور چراغ، خطوط جاده و کارت‌های شناور از آمار جدا شده‌اند.
- فرم تسویه: گرید دوستونه صریح، فیلدهای یکدست، کارت پرداخت و چک‌باکس نمونه بدون استایل پیش‌فرض مرورگر.

## صفحه‌های پوشش‌داده‌شده

خانه، فروشگاه/دسته/برند، جستجو، تک‌محصول، سبد، تسویه، رسید سفارش، حساب/سفارش‌ها/آدرس‌ها، خودروی من، درباره، تماس، FAQ، راهنما/مقاله، مرجوعی، گارانتی، حریم خصوصی، وبلاگ/آرشیو و ۴۰۴.

## پیش‌نمایش تعاملی

```bash
node preview/server.mjs
# http://localhost:3000
```

پیش‌نمایش از همان فایل‌های CSS/JS/تصویر قالب استفاده می‌کند. داده‌ها نمونه‌اند؛ سبد، علاقه‌مندی، مقایسه، خودرو و سفارش فقط در `localStorage` مرورگر ذخیره می‌شوند. هیچ پرداخت یا ارسال واقعی وجود ندارد. صفحه `/pages` نقشه همه صفحه‌های پیش‌نمایش را نشان می‌دهد.

## تست

```bash
node tools/php-run.mjs tools/php-lint.php theme plugins
node tools/php-run.mjs tools/php-test.php
# اختیاری، نیازمند playwright و @sparticuz/chromium:
node tools/preview-smoke.mjs
```

تست دودی پیش‌نمایش ۲۳ مسیر را باز می‌کند، سرریز افقی دسکتاپ/موبایل، منوی موبایل، جستجو، فیلتر خودرو، افزودن به سبد، کد تخفیف، تسویه نمایشی و حالت کاهش حرکت را بررسی می‌کند.

## بسته نصب

```bash
bash tools/build-release.sh        # سبک
bash tools/build-release.sh --full # کامل، اگر ZIPهای المنتور در ریشه باشند
```

خروجی در `releases/` قرار می‌گیرد.
